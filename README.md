# Yeonsik

Computer Science student building software around problems I actually encounter.

## What I'm building

- **[Personal OS](https://github.com/Yeon-sik/Personal-OS)** — A local-first desktop app for notes, tasks, and fitness records. Local storage and account sync paths are implemented; Windows release and cross-device behavior still need further verification.
- **[FitnessApp](https://github.com/Yeon-sik/Yeonsik-Fitness-App)** — An Android app for recording workouts, cardio, meals, and progress, with detailed records kept locally. Android features are implemented, while physical-device and interactive iOS verification remain limited.
- **[OCR-App](https://github.com/Yeon-sik/OCR-App)** — Android and desktop tools for capturing receipts or nutrition labels, extracting text, and reviewing structured records against the source. Real-document accuracy and some device and remote-service flows still need verification.
- **[PriceTrace](https://github.com/Yeon-sik/PriceTrace)** — A browser app for browsing prices observed on receipts and managing item allocation and settlement locally. These are past purchase observations, not live store prices.

## How I work

Problem → Requirements → Data / domain model → System boundaries → Implementation → Verification → Documentation

I use AI actively to implement and review. Generated code and AI inferences are starting points; source evidence, tests, and observed behavior determine what I can claim.

## Currently learning

- How to make local-first data, account sync, and cross-app data contracts reliable.
- How to verify OCR and mobile workflows with real source documents, devices, and remote services.
